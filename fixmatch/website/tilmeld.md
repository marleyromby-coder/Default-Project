# Tilmeld din virksomhed

Kom gratis på FixMatch, hvor kunder i nærheden sammenligner håndværkere og værksteder på pris, afstand og anmeldelser fra brugere via FixMatch – og ringer direkte til jer.

- **Gratis.** Ingen gebyrer pr. kunde eller pr. opkald.
- **I bestemmer.** Vi viser kun det, I selv skriver her, og I kan altid få det rettet eller fjernet.
- **Ingen kan købe sig foran.** Rækkefølgen bygger på pris, afstand og anmeldelser fra brugere via FixMatch, og brugeren vælger selv, hvad der vejer mest. Rækkefølgen kan ikke købes. Har I ingen anmeldelser endnu, tæller I som 5 neutrale anmeldelser på 4,0.
- **Anmeldelser.** Kun brugere, der har kontaktet jer gennem FixMatch, kan anmelde jer – én gang hver. Vi tjekker, at de har trykket Ring eller skrevet til jer i FixMatch. Vi kan ikke se, om opkaldet blev besvaret, eller om opgaven blev udført.
- **Bliv verificeret.** Sæt flueben, så tjekker vi CVR, ejer og autorisation, og I får et flueben ved navnet i appen. Det er også gratis.
